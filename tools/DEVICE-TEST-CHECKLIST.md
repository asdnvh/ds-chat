# DS Chat Android 真机测试清单

> 适用版本：`DSChat-0.1.1-debug.apk` / `DSChat-0.1.1-release.apk`
> 包名：`com.dschat.android`　主 Activity：`com.dschat.android.MainActivity`
> 环境要求：Android 8.0（API 26）及以上；需要网络（API 直连 `https://api.deepseek.com`）。
> 说明：本清单用于真机手动验收。安装命令（可选，替代点按安装）：
> `adb install -r -g DSChat-0.1.1-debug.apk`
> debug 包已开启 WebView 远程调试，可在桌面 Chrome 打开 `chrome://inspect` 查看页面控制台。

## 测试前准备

- [ ] 手机开启"允许安装未知来源应用"，安装 debug（或 release）APK 并成功打开 App。
- [ ] 准备一个可用的 DeepSeek API Key、一张本地图片、一个此前导出的历史 ZIP 文件（用于导入用例）。
- [ ] 全程观察：页面是否白屏；出现异常时记录时间点，便于用 `adb logcat -s DSChatApp DSChatWeb AndroidRuntime` 抓日志。

## 用例清单

| # | 操作步骤 | 预期结果 |
|---|----------|----------|
| 1 | 首次冷启动 App（先清除数据或全新安装） | 自动弹出"设置"页（Dialog/Sheet），提示填写 API Key；未填 Key 时发送按钮不可用或给出提示，不崩溃 |
| 2 | 在设置页填入有效 API Key 并保存，回到主界面发送"你好" | 消息先显示为用户气泡，随后 AI 回复**流式**逐字出现；期间发送/停止按钮状态正确，完成后可继续对话 |
| 3 | 点附件/图片按钮，从相册选一张图片发送 | 聊天中出现图片缩略图；发送后模型能识别图片内容并正常回复，无崩溃、无超大 OOM |
| 4 | 在输入框长按/使用系统粘贴，粘贴一张剪贴板图片 | 图片被识别为附件出现在待发送区，可正常发送并展示 |
| 5 | 点麦克风按钮首次使用语音输入 | 弹出系统麦克风授权弹窗；允许后开始录音（有录音状态提示），松手/结束后文字被识别填入输入框或自动发送 |
| 6 | 对一条 AI 回复点"朗读"（TTS） | 设备有声音播放，朗读内容与消息文本一致；再次点击可停止；系统 TTS 引擎缺失时有友好提示而非崩溃 |
| 7 | 打开侧边栏/设置，执行"导出历史" | 提示导出成功；用系统文件管理器确认文件出现在 `下载/DSChat`（或应用提示的目录），文件名带时间戳 |
| 8 | 执行"导入历史"，选择准备好的历史 ZIP | 导入成功提示；会话列表/消息恢复为 ZIP 中的内容；损坏或非 ZIP 文件被拒绝且不崩溃 |
| 9 | 在设置中切换深色模式（浅色 ↔ 深色） | 页面整体配色立即切换，状态栏图标/背景色随之变化、文字可读（不出现黑底黑字） |
| 10 | 发送包含 Markdown 代码块和数学公式的回复（让 AI 输出代码与 `$E=mc^2$`） | 代码块有高亮与等宽字体、可横向滚动；公式正确渲染为公式而非源码；长代码不撑破布局 |
| 11 | 点击消息中的外部链接（如 https://example.com） | 用系统默认浏览器打开链接，App 自身不跳转、不白屏，返回 App 后状态正常 |
| 12 | 打开设置弹窗后按一次返回键；再在主界面连续按两次返回键 | 第一次返回仅关闭设置弹窗；主界面第一次返回给出"再按一次退出"提示，第二次返回退出 App |
| 13 | 在对话进行中旋转屏幕（横屏 ↔ 竖屏） | 页面重新布局不丢失当前会话与输入框草稿，不重新加载白屏，不崩溃 |
| 14 | 聚焦输入框弹出软键盘 | 输入框与最新消息不被键盘遮挡（窗口 resize 正常），可正常滚动查看历史消息 |
| 15 | 在最近任务中划掉（杀进程）App，重新打开 | App 正常冷启动，历史会话与设置（API Key、主题等）仍在；不出现崩溃或数据丢失 |
